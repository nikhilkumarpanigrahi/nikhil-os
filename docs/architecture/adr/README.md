# Architecture Decision Records

Significant architectural decisions for NIKHIL//OS are recorded as ADRs so
the reasoning survives the people who made it.

## How to add an ADR

Use [docs/08-ADR-TEMPLATE.md](../08-ADR-TEMPLATE.md). Number sequentially
(`ADR-0001`, `ADR-0002`, …). One decision per ADR. Link the ADR from the code
or docs it affects.
